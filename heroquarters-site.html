🛡️ The Shield

Client privacy isn't a feature. It's the whole point. Here's how we keep the villains' identities classified.

🛡️
  • 🔒
    Query-level privacy enforcement
    Sidekick routes never touch the clients table — not even for a peek. It's not hidden in the UI; it's absent from the query entirely.
  • 🔑
    Bcrypt password hashing
    Werkzeug's industry-standard hashing means passwords are never stored in plain text — anywhere, ever.
  • 🏷️
    Role-gated routes
    Every admin route verifies role at the Python level. Bypassing the UI doesn't grant access — the server still says no.
  • 📂
    File access verification
    Every file download checks: does this sidekick own this mission? A direct URL to another mission's file returns 403, no exceptions.
  • 🌐
    HTTPS + domain isolation (roadmap)
    Web deployment will run behind Nginx with Let's Encrypt SSL. All traffic encrypted, no exceptions.
