Day Soft is packed with practical features for real-world financial tracking — designed for simplicity, built for reliability.

📒

Ledger Management

Create and manage unique ledgers with IDs, names, phone numbers, and locations. Smart validation prevents duplicate entries.

📅

Day Book Entry

Log daily credit and debit entries against any ledger with date selectors, running totals, and multi-row support for multiple parties.

📈

Statement Reports

Filter entries by date range and ledger. View, delete, and export your complete transaction history to Excel in one click.

🔐

Login Security

Password-protected access ensures only authorised users open the software. Your financial data stays private and secure.

💾

Auto DB Backup

Automatic database backup every 30 minutes. Manual backups on demand. Restore any backup with admin password confirmation.

🕵️

Activity Logs

Every user action is timestamped and logged daily in readable log files — even DB restores are recorded for full audit trails.

🔍

Smart Search

Type any part of a ledger ID or name — Day Soft dynamically filters results as you type, case-insensitively, for quick selection.

🖼️

Custom Splash Screen

Place your own images in the splash folder — the app picks one at random on every launch for a personal, branded feel.

📤

Excel Export

Export any ledger's complete transaction history to Excel format for sharing, printing, or further analysis in seconds.

Three core modules

Simple structure.
Powerful results.

Day Soft is organised into three focused modules — each doing its job clearly, without overlap or confusion.

01

Ledger Creation

Set up accounts for every client, vendor, or project. Each ledger gets a unique ID and name with optional phone and location fields. Fully validated — no duplicates allowed.

Setup once, use always
02

Day Book

Enter daily transactions against any ledger. Add credits and debits, write particulars, choose the date, and save — all in a clean tabular view with real-time running totals.

Daily entry made easy
03

Day Book Statement

Query your history by ledger and date range. View all transactions in latest-first order, delete individual rows or all entries, and export the full statement to Excel.

Reports at your fingertips
Why offline-first

Runs on your machine.
Answers to no one else.

Day Soft stores everything on your own computer. No cloud sync. No servers. No risk. Just your data, in your hands.

⚡

Blazing fast

No network latency. All queries run locally on SQLite — results appear instantly, even with thousands of entries.

🔒

Truly private

Your transaction data never leaves your computer. No analytics, no telemetry, no third-party access — ever.

📡

Works without internet

Power cuts, ISP outages, remote locations — Day Soft keeps working regardless of connectivity.

🗃️

You own your data

The SQLite file is yours. Back it up to USB, restore from any point, or archive old databases anytime.

🛡️

Backup & restore

Auto-backup every 30 minutes, manual backups by date folder, and admin-verified restore from any saved DB.

🖥️

Dedicated window app

Runs in its own native window — not a browser tab. Maximise, resize, or keep it compact alongside your other work.

Under the hood

Built on proven,
open technology.

Day Soft uses a modern, stable stack chosen for performance, portability, and long-term reliability — not trends.

Python — Core Language
PySide6 — Native GUI
SQLite — Local Database
Virtual Environment — Isolated Runtime
OpenPyXL — Excel Export
Auto-Backup Engine — 30-min Cycles
Activity Logger — 15-sec Timestamping
Qt Calendar Widget — Date Picker
STACK SUMMARY

python + pyside6 + sqlite3
→ single user, single machine
→ zero external dependencies
→ runs on Windows / macOS / Linux

Day Soft is packaged in a Python virtual environment so it never conflicts with other software on your machine. Clean install, clean uninstall.
