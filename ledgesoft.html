// beta transparency · known behaviour
We Build in the Open — Including the Honest Bits
In the current beta, the Dashboard unassigned project count may not refresh automatically after a project assignment is completed — it reflects the state at login. This is by design for now: the dashboard reads a snapshot on load to keep it fast and lightweight.

We believe software you can trust is software that's honest with you. Every great platform ships its first version with a list of things to improve — and we'd rather be upfront about it than pretend it isn't there. A live refresh for the assignment counter is already on our roadmap for v1.1. Until then, a simple page refresh brings everything up to date.

That's the kind of software LedgeSoft is: transparent, improving, and always listening.
